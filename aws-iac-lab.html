ECS và EKS không thuộc nhóm nào ở trên — chúng là nơi container chạy, không phải công cụ deploy. Gộp chung 8 cái vào một danh sách phẳng là lý do khái niệm này hay gây rối.


    
Biết tên là đủ, chưa cần đào sâu

    

      
Dịch vụMột câu để nhớ

      
        
Elastic BeanstalkUpload code (Java/.NET/PHP/Node.js/Python/Ruby/Go/Docker) → tự dựng hạ tầng. Web server environment (HTTP) hoặc Worker environment (job dài, tích hợp SQS). Cấu hình lưu trong thư mục .ebextensions.

        
Amazon ECS AnywhereChạy cluster ECS ngay tại server on-premises thay vì trên AWS, vẫn quản lý chung qua ECS console.

        
Amazon EKS (+ Outposts / Anywhere / Distro)Bản Kubernetes quản lý của AWS — 4 cách triển khai, từ chạy trên AWS đến tự quản lý hoàn toàn on-premises.

        
AWS OpsWorksQuản lý server bằng Chef/Puppet — công nghệ IaC đời trước CloudFormation.

        
AWS ProtonPlatform team phát template chuẩn (container/serverless) cho hàng trăm dev dùng lại qua cổng self-service.

        
Serverless Application RepositoryKho chia sẻ app serverless (đi kèm SAM) công khai hoặc nội bộ trong tổ chức.

      
    

  


  
  

    
Thuật ngữ cần nhớ

    
Bấm để mở từng thẻ.

    

      
Infrastructure as Code (IaC)
Hạ tầng (server, DB, mạng) được viết ra bằng file text. Chạy file đó thì AWS tự dựng — không bấm tay trên console. Là khái niệm gốc của toàn bộ trang này.

      
Stack
Một nhóm tài nguyên được dựng cùng nhau từ một file template. Xoá stack = xoá sạch mọi thứ trong đó — như nút "Xoá Stack" ở Tab 2.

      
Change Set
Chế độ xem trước. Cho biết khi sửa template thì tài nguyên nào bị tạo mới, sửa, hay xoá — trước khi thực sự chạy. Thử ở mục "Cập nhật Stack đang chạy".

      
Nested Stack
Tách một template lớn thành nhiều template nhỏ theo tầng (compute, database, network) để sửa tầng này không ảnh hưởng tầng kia. Vẫn nằm trong một tài khoản AWS.

      
Stack Set
Một Stack thường chỉ áp dụng cho một tài khoản AWS. Stack Set mở rộng điều đó: tạo/cập nhật/xoá cùng một stack trên nhiều tài khoản và nhiều region cùng lúc, quản lý tập trung từ một tài khoản Administrator trong AWS Organizations. Khác Nested Stack ở chỗ: Nested Stack chia nhỏ theo tầng trong 1 account, Stack Set nhân bản cùng 1 stack ra nhiều account/region.

      
AWS CDK
Viết hạ tầng bằng Python (hoặc TypeScript) thay vì YAML. Cuối cùng vẫn sinh ra CloudFormation phía sau — xem cột "AWS CDK" ở Tab 2 để so cú pháp.

      
AWS SAM
Bản rút gọn của CloudFormation, chuyên cho Lambda + API Gateway + DynamoDB. Ít dòng cấu hình hơn nhiều so với viết CloudFormation thuần.

      
ECS + Fargate
Nơi container thực sự chạy. ECS quản lý container; Fargate là chế độ không cần quản server, chỉ khai báo CPU/RAM.

      
CodeDeploy
Chỉ đẩy phiên bản code mới lên hạ tầng đã tồn tại — có thể là EC2, ECS, Lambda, hoặc cả server on-premises. Không tạo hạ tầng — khác biệt quan trọng nhất so với CloudFormation/SAM.
